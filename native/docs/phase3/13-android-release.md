## Plan

**Findings.** `sharp` 0.35.5 (+ linux-x64 libvips) exists only in repo-root `node_modules` (via `@vite-pwa/assets-generator`); `native/` has `@expo/image-utils`/`jimp-compact` (no SVG rasterising). No ImageMagick/rsvg/inkscape. `react-native-audio-api` 1.0.0: `PlaybackNotificationManager.show()` defaults to `android.R.drawable.ic_media_play` but accepts `androidSmallIcon: '<drawable name>'` (resolved via `ResourceDrawableIdHelper`, so a drawable must exist in the app's `res/`); only the short-lived shutdown placeholder of `CentralizedForegroundService` stays hard-coded. SDK 58 config types have no `edgeToEdgeEnabled` (edge-to-edge is always on; nothing to set). Expo submit docs (fetched today): `eas submit` *can* create the first internal-track release, `releaseStatus: "draft"` uploads without rollout; key via `serviceAccountKeyPath` or `eas credentials`. App uses `expo-haptics` (needs VIBRATE); no `fetch`/analytics in `src/`; AsyncStorage holds settings locally only.

**1. Assets — `scripts/generate-assets.mjs`** (Node ESM, run `node scripts/generate-assets.mjs` from `native/`). Loads `sharp` with `createRequire` from `../node_modules` (clear error "run npm install at repo root" if missing). Reads the waveform `<path d>` from `../public/favicon.svg` (single source), wraps it in per-target SVGs, rasterises:
- `icon.png` 1024, full-bleed `#EEE7D6`, waveform `#C4502F` (store/iOS/fallback; no transparency)
- `android-icon-foreground.png` 1024 transparent, waveform inside the 66% safe zone

- `splash-icon.png` 1024 transparent, accent waveform (readable on cream and `#0F0E0C`)

- `notification-icon/ic_notification_{mdpi..xxxhdpi}.png` 24/36/48/72/96 px, white alpha-only
